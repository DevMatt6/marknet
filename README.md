# New Project

Next.js 16 · React 19 · TypeScript · Tailwind CSS v4 · shadcn/ui · Framer Motion · Lenis

## Struttura

```
app/              # Pagine e route
components/
  ui/             # shadcn componenti
  layout/         # Header, Footer
  sections/       # HeroSection, ecc.
  shared/         # Componenti condivisi
config/           # Dati progetto (site.ts, nav.ts...)
lib/              # Helper tecnici
providers/        # React context providers
types/            # Tipi TypeScript
public/
  images/
  icons/
  fonts/
```

## Getting Started

```bash
pnpm install
pnpm dev
```

## Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4 + tw-animate-css
- **Components:** shadcn/ui (@base-ui/react)
- **Animation:** Framer Motion
- **Scroll:** Lenis
- **Icons:** Lucide React
- **Deploy:** Vercel
